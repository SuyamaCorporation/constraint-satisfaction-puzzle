# Constraint Satisfaction Puzzle Generator

**Category:** Puzzle / Logic

Generates Latin square logic puzzles (4×4, 5×5, 6×6) with configurable constraint density. Constraints include row/column sums, greater-than relationships, and diagonal sums. Features a cycle-to-fill input system, hint button (reveals one cell), solution checker with color feedback, and analytics tracking time, hints used, and error count.
